# 문자열 덧셈 계산기 (String Calculator)
## 기능 요구사항
- 입력된 문자열에서 숫자를 추출해 합을 반환한다.
- 기본 구분자: 쉼표(`,`), 콜론(`:`).
- 커스텀 구분자: 입력 맨 앞 `"//<delim>\n"` 형식으로 지정 (한 글자).
- 잘못된 입력 시 `IllegalArgumentException` 발생 후 **자연 종료**(※ `System.exit()` 사용 금지).

---
## 구현할 기능 목록
### 1) 입출력
- 결과 형식: `결과 : <합계>` 출력
- 잘못된 입력 시 `[ERROR] <메시지>` 출력 후 종료
- 프로그램 종료 전 `Console.close()` 호출

### 2) 문자열 파싱
- 빈 문자열 입력 시 `0` 반환
- 기본 구분자 `,` `:` 로 분리
- `"//<구분자>\n"` 형식의 커스텀 구분자 지원
- 구분자를 기준으로 숫자 토큰 분리

### 3) 유효성 검증
- 커스텀 구분자 형식 검증 (`//`는 맨 앞만 허용, 한 글자, `\n` 필수)
- 숫자 이외의 값 입력 시 예외 발생
- 음수 입력 시 예외 발생

### 4) 계산 로직
- 파싱된 숫자들을 모두 더해 합계 반환

### 5) 예외 처리
- 잘못된 입력 형식, 음수, 공백 등 예외 발생 시 `IllegalArgumentException` 처리

##  클래스 구조

| 클래스명 | 역할 |
|-----------|------|
| **Application** | 프로그램 실행의 시작점, 전체 흐름 제어 |
| **ConsoleView** | 입출력 담당 |
| **Calculator** | 숫자 합산 로직 |
| **StringParser** | 입력 문자열 파싱 및 구분자 적용 |
| **DelimiterExtractor** | 커스텀 구분자 추출 |
| **Validator** | 숫자 및 형식 검증 |
